Privacy Policy

Last updated: October 31, 2026

The "Baby" application is a private tool used only by the owner of the Only Baby YouTube channel to upload videos to that channel.

What data the app uses

The app uses the YouTube Data API to upload videos, titles, descriptions and thumbnails to the owner's own channel. It reads only the basic information of that channel (its name and ID) to confirm the upload destination.

What the app does not do

  • It does not collect, store or share personal data of viewers or any other people.
  • It does not access other users' Google or YouTube accounts.
  • It does not sell data or use it for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
